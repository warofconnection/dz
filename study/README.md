# Материалы для подготовки к защите

Это отдельное пособие по текущему ДЗ1 L1–L2, не дополнительная часть отчёта для преподавателя.

- `Пособие_для_защиты_ИТС_вариант8.pdf` — 20 страниц: термины, структура сети, прикладные задачи, расчёты, оборудование, ограничения, рассказ по 18 слайдам и вопросы.
- `Памятка_перед_защитой.pdf` — 2 страницы для повторения.
- Одноимённые DOCX — редактируемые версии; MD — текстовые исходники.
- `clinic8-defense-guide.zip` — оба пособия в PDF и DOCX.

Порядок подготовки: сначала разделы 1–5; затем самостоятельно воспроизвести три расчёта из памятки; после этого проговорить рассказ по слайдам и ответить на вопросы раздела 12. Подробный план тренировки находится в разделе 15.

Уточнение для защиты: резерв физических портов зависит от интерфейса аплинка. В филиале при медном аплинке к выбранному CRS328 занято 22 из 24 медных портов. Основные сдаваемые документы в рамках создания пособия не менялись.

Воспроизведение: `python tools/build_study_guide.py`, затем экспорт двух DOCX в PDF через LibreOffice. Для Word требуется python-docx; в текущей среде доступны DejaVu Sans и LibreOffice.
