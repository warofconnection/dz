# Сценарий отозван после сбоя Packet Tracer

**Не запускать `clinic8-all-in-one.js`, `build-clinic8.js` или `finish-clinic8.js`.** Пользователь сообщил о полном закрытии Packet Tracer при запуске версии v3. Реальные испытания не пройдены; причина сбоя пока не установлена. Тесты с заменами IPC оказались недостаточны для проверки устойчивости самого приложения.

Опубликованные копии отключены по умолчанию: `main()` выводит `WITHDRAWN` и не обращается к IPC. Самостоятельная остановка модуля из исполняемого JavaScript удалена как потенциально опасный вызов; причинная связь со сбоем не доказана. Не включать `BUILDER_ENABLED` в реальном Packet Tracer без диагностики.

Для сохранения работы:

1. Открыть Packet Tracer; если предложено восстановление проекта, сохранить восстановленную копию под новым именем.
2. Открыть ранее сохранённый `clinic8-devices.pkt`, если он есть. Не перезаписывать его до проверки содержимого.
3. В Configure PT Script Modules отключить автозапуск Clinic8 Builder: установить Disabled или удалить его регистрацию. Файл проекта от удаления регистрации скрипта не удаляется.
4. Зафиксировать последний этап/сообщение перед закрытием приложения. Если есть сохранённый `.pkt`, передать его для проверки структуры.

Документы, портовая ведомость, адресация и IOS-конфигурации остаются в репозитории. Функциональность и устойчивость Cisco-модели не подтверждены. Архитектура дальнейшей автоматизации требует проверки на минимальном примере в реальном Packet Tracer до масштабирования.
