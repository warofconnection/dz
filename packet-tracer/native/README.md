# Проверка восстановления модели без скриптов

Источник — `../recovery/clinic8-one-link-original.pkt`, сохранённый пользователем в Packet Tracer 8.2.2. Оригинал сохранён без изменений.

## Сначала открыть clinic8-wired.pkt

1. На GitHub открыть `clinic8-wired.pkt` и нажать **Download raw file** (кнопка скачивания).
2. В Packet Tracer использовать **File → Open** и выбрать скачанный файл. Script Modules для этого не нужны.
3. Проверить, что появились кабели между устройствами. Зелёный цвет всех соединений пока не требуется: IP, VLAN и службы в этой копии ещё не настроены.
4. Если модель открылась, сохранить через **File → Save As** под новым именем. Исходники не перезаписывать.

В копии сохранены 116 устройств источника (113 проектных и 3 автоматически созданных устройства питания) и первый настоящий кабель. Добавлены остальные 111 проектных кабелей. Не добавлены и не запущены скрипты.

**Открытие в Cisco пока НЕ ПРОВЕРЕНО.** Проверки контейнера, XML, ссылок устройств и уникальности портовых соединений не заменяют проверку в симуляторе. При ошибке открытия сохранить сообщение об ошибке и вернуться к оригиналу.

## Дополнительная копия clinic8-wired-ios.pkt

Содержит те же кабели и подготовленные строки running/startup-конфигураций 13 маршрутизаторов и коммутаторов. Применение этих конфигураций самим Cisco пока не проверено. Эта копия предназначена для следующего этапа после успешного открытия первой.

ПК, принтеры, IP-адреса серверов, DNS, почта и Wi-Fi ещё требуют настройки. Ни одна из копий пока не является готовой к сдаче моделью. Функциональные проверки остаются NOT_RUN.

## Воспроизведение

Требуется Python 3 и `twofish==0.3.0` (для установки расширения нужен C-компилятор). Из корня проекта:

```bash
python3 tools/prepare_native_pkt.py packet-tracer/recovery/clinic8-one-link-original.pkt
```

Генератор работает с документом офлайн, проверяет EAX и zlib, сохраняет исходник, создаёт две копии и `validation.json`. Авторизация Cisco и выполнение Script Modules не используются.
