# ИТС — домашнее задание № 1, вариант 8

**Автор:** Устинов Илья Максимович, ИУ10-59. **Преподаватель:** Федорова В. А.

Проект городской поликлиники с центральным двухэтажным корпусом и двумя одноэтажными филиалами в разных районах города.

## Статус ДЗ1: L1–L2

Презентация и расчёты переработаны под физический и канальный уровни: убраны адресация, конфигурация служб и результаты испытаний прежней настроенной модели. Бауманский шаблон сохранён. Все 14 пунктов представлены на 18 слайдах, пункт 13 содержит подлинный общий снимок цветной модели Cisco.

Новая концепция — единый диагностический архив трёх площадок. Уточнены трассы вдоль стен и потолочного лотка: 96 постоянных линий, 2904,8 м Cat6; серверы подключены отдельными патч-кордами. Расчётная стоимость — 7 907 116 руб. Для трёх типов сетевого оборудования найдены опубликованные каталоговые цены; остальные строки остаются предварительной оценкой. Подбор конкретных моделей ПК, серверов, МФУ и пассивных компонентов с проверенными ценами ещё не завершён. Эти строки нельзя считать подтверждёнными предложениями поставщиков.

Для следующей проверки и снимка использовать `packet-tracer/clinic8-L1-L2-ready.pkt`: цветная копия с включёнными подключёнными портами и без адресации. Открытие подтверждено; получен общий снимок со включёнными проводными соединениями. `packet-tracer/clinic8-L1-L2.pkt` открыт в Cisco без настроек. Новая `clinic8-L1-L2-annotated.pkt` дополнена цветными областями и подписями; её открытие ещё нужно проверить. Скрипты в Cisco запускать не требуется. Историческая настроенная модель сохранена отдельно для следующих заданий.

Текущий комплект для просмотра: `deliverables/ИТС_ДЗ1_Вариант8_L1-L2.zip`. Остаются уточнение остальных моделей/цен и проверка правил названия файлов на сайте сдачи. Доступ к сайту из облачной среды отклонён прокси (HTTP 403).

## Материалы

Презентация оформлена на основе предоставленного бауманского шаблона; исходник сохранён в `templates/Бауманский_шаблон.pptx`.

Единый архив L1–L2 для скачивания: `deliverables/ИТС_ДЗ1_Вариант8_L1-L2.zip` (PPTX, PDF, DOCX, PKT и исходные изображения схем).

- `docs/Презентация_вариант_8.pdf` — PDF для просмотра оформления.
- `docs/Презентация_вариант_8.pptx` — 18 слайдов по всем 14 пунктам методички; пункт 10 занимает четыре слайда, пункт 13 — два.
- `docs/Расчёты_вариант_8.docx` — допущения, расчёт нагрузок, характеристики оборудования, индивидуальные кабельные трассы, смета.
- `diagrams/floor-C1.png`, `floor-C2.png`, `floor-B1.png`, `floor-B2.png` — планы с размерами, рабочими местами и трассами.
- `diagrams/site.png`, `org.png`, `logical-draft.png` — схема площадок, организационная структура, проект логической топологии. Последний файл **не является скриншотом Cisco**. Актуальный снимок — `diagrams/packet-tracer-l1l2.png`; `packet-tracer.png` относится к прежней настроенной схеме.
- `docs/cable-routes.csv`, `project-data.json` — исходные числовые данные.
- `packet-tracer/clinic8.pkt` — историческая настроенная модель; 117 сетевых устройств и 3 автоматически созданных устройства питания, 112 кабелей.
- `packet-tracer/final-inspection.json` — результат проверки сохранённого документа, включая режимы планшетов.
- `packet-tracer/ports.csv`, `topology.dot`, `configs/` — портовая ведомость, редактируемая схема, 13 подготовленных конфигураций устройств.
- `packet-tracer/ASSEMBLY.md` — ручная сборка в Packet Tracer 8.2.2, GUI-службы и приёмочные проверки.
- `packet-tracer/clinic8-all-in-one.js`, `AUTOMATION.md` — сценарий **отозван и отключён** после сообщения о полном закрытии Packet Tracer. Причина не установлена; не запускать в реальной программе до диагностики. Тесты с заменами IPC не подтвердили устойчивость Cisco.
- `packet-tracer/native/README.md` — копии `.pkt` с добавленными кабелями, ограничения и порядок проверки без скриптов.
- `packet-tracer/validation-results.csv` — фактические пользовательские PASS/FAIL и ещё не выполненные проверки; первоначальные сбои сохранены как история.
- `docs/requirements-checklist.md` — соответствие методичке и незакрытые требования.

## Проектные решения

112 сотрудников, 84 ПК, 8 сетевых МФУ, 4 точки доступа, 3 сервера: 99 проводных подключений. 6 коммутаторов доступа и 5 маршрутизаторов поликлиники. Дополнительные маршрутизатор и коммутатор оператора, внешний Server-PT и гостевые ноутбуки нужны только в модели и не входят в закупку поликлиники.

Этажная коммутация и маршрутизация между этажами/зданиями соблюдают прямое требование методички. Размеры помещений, расстояния, штат, нагрузки и цены выбраны как учебные допущения. Их нельзя выдавать за обследование существующей поликлиники.

## Воспроизведение материалов

Требуются Python 3, python-docx, python-pptx, Pillow и Graphviz (`dot`). В текущей облачной среде они уже присутствуют. Из корня репозитория:

```bash
python3 tools/build_deliverables.py
python3 tools/verify_project.py
```

Генераторы перезаписывают созданные документы. Правки готовых DOCX/PPTX сначала перенести в генератор или сохранить отдельную копию. Создание `.pkt` этими командами **не выполняется**. Использовать текущий checkout `/workspace/dz`; отдельный Git worktree для этой изолированной среды не нужен.
