# ИТС — домашнее задание № 1, вариант 8

**Автор:** Устинов Илья Максимович, ИУ10-59. **Преподаватель:** Федорова В. А.

Проект городской поликлиники с центральным двухэтажным корпусом и двумя одноэтажными филиалами в разных районах города.

## Статус

Получен сохранённый пользователем файл `packet-tracer/clinic8.pkt` для Cisco Packet Tracer 8.2.2.0400. Проверены целостность документа, состав устройств, кабели, VLAN и настройки Wi-Fi. Пользователь подтвердил связь между площадками и с внешним сервером, DNS/HTTP из B1, две передачи почты и гостевую изоляцию на четырёх площадках. После повторного открытия начальная ошибка DNS исчезла после ожидания/повторного запроса.

Стоимость оборудования оставлена как ориентировочная бюджетная оценка по принятому условию задания. Рыночные предложения не выдаются за проверенные источники цен. Все 14 пунктов отчёта представлены на 18 слайдах; приложены расчёты DOCX, настоящая модель `.pkt` и скриншот Cisco. В DOCX и PPTX используются нейтральные формулировки о результатах моделирования.

Границы фактических проверок и история диагностики сохранены отдельно в `validation-results.csv` и `final-inspection.json`.

## Уточнение ДЗ1: проектирование L1–L2

Подготовлена отдельная копия `packet-tracer/clinic8-L1-L2.pkt` без назначенной адресации и сетевой конфигурации. Настроенная `clinic8.pkt` сохранена отдельно. Открытие новой копии ещё требует проверки в Cisco. Презентация и ZIP пока отражают предыдущую версию; для сдачи по уточнению преподавателя их нужно переработать. Подробнее: `packet-tracer/L1-L2.md`.

## Проектные решения

112 сотрудников, 84 ПК, 8 сетевых МФУ, 4 точки доступа, 3 сервера: 99 проводных подключений. 6 коммутаторов доступа и 5 маршрутизаторов поликлиники. Дополнительные маршрутизатор и коммутатор оператора, внешний Server-PT и гостевые ноутбуки нужны только в модели и не входят в закупку поликлиники.

Этажная коммутация и маршрутизация между этажами/зданиями соблюдают прямое требование методички. Размеры помещений, расстояния, штат, нагрузки и цены выбраны как учебные допущения. Их нельзя выдавать за обследование существующей поликлиники.

## Воспроизведение материалов

Требуются Python 3, python-docx, python-pptx, Pillow и Graphviz (`dot`). В текущей облачной среде они уже присутствуют. Из корня репозитория:

```bash
python3 tools/build_deliverables.py
python3 tools/build_configs.py
python3 tools/build_cisco_script.py
python3 tools/verify_project.py
node tools/test_cisco_builder.js
```

Генераторы перезаписывают созданные документы. Правки готовых DOCX/PPTX сначала перенести в генератор или сохранить отдельную копию. Создание `.pkt` этими командами **не выполняется**. Использовать текущий checkout `/workspace/dz`; отдельный Git worktree для этой изолированной среды не нужен.
