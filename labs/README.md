# Лабораторные работы по ИТС

Файлы для Cisco Packet Tracer 8.2.2.0400:

- `lab1.pkt` — итоговая схема лабораторной 1: DNS, HTTP, DHCP, SMTP/POP3 и два варианта беспроводного подключения.
- `lab2.pkt` — две отдельные схемы лабораторной 2: VLAN/trunk с маршрутизатором и корпоративная сеть с ACL.
- `its-labs-1-2.zip` — оба PKT и подробная инструкция `Как_проверить.txt`.

Открывать через File → Open; скрипты не требуются. Проверены целостность файлов и согласованность настроек. Открытие и функциональные испытания в Cisco пока не выполнены: облачное приложение требует вход. Ожидаемые результаты и отличия от неточных промежуточных примеров методички указаны в инструкции.
