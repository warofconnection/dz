# Лабораторные работы ИТС — проверка совместимости

Использовать обновлённые `lab1-822.pkt` и `lab2-822.pkt`, целевая версия Cisco Packet Tracer 8.2.2.0400. Старый lab1 показал ошибку несовместимости при открытии. Его записи коммутатора из образца PT 5.2 заменены на записи из PT 8.1; аналогично обновлён маршрутизатор второй работы. Исправлены размещение устройств и сериализация XML.

Проверены целостность контейнера, чтение XML библиотеками Qt из Cisco и согласованность настроек. **Открытие обновлённых файлов и обмен пакетами пока не подтверждены**; эти проверки не заменяет XML-парсер. Подробности — `compatibility-check.json`.

`lab1-822.pkt` — службы и Wi-Fi; `lab2-822.pkt` — VLAN/trunk/маршрутизатор и отдельная корпоративная схема с ACL. `its-labs-1-2.zip` содержит обновлённые файлы и инструкцию. Скрипты в Packet Tracer запускать не требуется.
