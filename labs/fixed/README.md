# Лабораторные для Packet Tracer 8.2.2.0400

`lab1-fixed.pkt` — лабораторная 1: сетевые службы, почта, WIFI1/WIFI2.
`lab2-fixed.pkt` — лабораторная 2: две независимые итоговые схемы — VLAN 2/3 с маршрутизатором и корпоративная сеть VLAN 10–13 с ACL.

В предыдущих файлах отсутствовал обязательный элемент EMAIL_CLIENT/NO_OF_MAILS на PC0 и Laptop0. Функция чтения CEmailClient::deserialize в Packet Tracer 8.2.2 возвращает ошибку при отсутствии этого элемента. В обе копии добавлены только два нулевых счётчика писем. Остальные байты расшифрованных документов не изменены относительно соответствующих копий native.

Контрольная копия исходного пользовательского проекта открылась; это подтвердило, что сам способ записи контейнера подходит. Проверка нового обязательного поля выявляет дефект во всех проверенных старых копиях и проходит для исправленных. Также пройдены проверки адресации, DHCP/DNS, Wi-Fi, почты, VLAN/trunk и правил ACL. Открытие новых файлов и передачу пакетов необходимо подтвердить в Packet Tracer; облачная установка требует входа Cisco.

Открывать через File → Open как отдельные проекты, без запуска скрипта. Начать с lab1-fixed.pkt, затем lab2-fixed.pkt. Действия для проверки — в Как_проверить.txt. При первом ping возможны потери из-за ARP; повторная проверка должна пройти, за исключением запретов ACL.

В схеме А лабораторной 2 trunk между Switch0 и Switch1 подключён к Fa0/7, а Router0 — к Fa0/6 обоих коммутаторов.
